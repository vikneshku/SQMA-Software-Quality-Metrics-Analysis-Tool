Complexity Values (Histogram)
How to read: a histogram groups the values into equal class intervals (bins) and counts how many functions fall in each. The x-axis shows the complexity range of each bin, the y-axis shows the frequency (number of functions), and a tall bar means many functions have that complexity.
Rule: number of bins k = ceil(1 + log2 n) (Sturges' rule); class width = ceil((max - min + 1) / k).
